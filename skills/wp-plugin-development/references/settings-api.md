# Settings API (admin options)

Use this file when adding settings pages or storing user-configurable options.

Core APIs:

- `register_setting( $option_group, $option_name, $args )`
- `add_settings_section( $id, $title, $callback, $page )`
- `add_settings_field( $id, $title, $callback, $page, $section, $args )`
- In the page: `settings_fields( $option_group )`, `do_settings_sections( $page )`, `submit_button()`

## Pattern

Store related settings as one array option to keep the options table small.

```php
add_action( 'admin_init', function () {
	register_setting(
		'acme_reviews', // option group, used by settings_fields()
		'acme_reviews_settings',
		array(
			'type'              => 'object',
			'default'           => array( 'enabled' => false, 'title' => '' ),
			'sanitize_callback' => 'acme_reviews_sanitize_settings',
			'show_in_rest'      => false, // set a schema if exposing via /wp/v2/settings
		)
	);

	add_settings_section( 'acme_reviews_main', __( 'General', 'acme-reviews' ), '__return_false', 'acme-reviews' );

	add_settings_field(
		'acme_reviews_title',
		__( 'Widget title', 'acme-reviews' ),
		function () {
			$settings = get_option( 'acme_reviews_settings', array() );
			printf(
				'<input type="text" class="regular-text" id="acme_reviews_title" name="acme_reviews_settings[title]" value="%s">',
				esc_attr( $settings['title'] ?? '' )
			);
		},
		'acme-reviews',
		'acme_reviews_main',
		array( 'label_for' => 'acme_reviews_title' )
	);
} );

function acme_reviews_sanitize_settings( $input ) {
	$input = is_array( $input ) ? $input : array();
	return array(
		'enabled' => ! empty( $input['enabled'] ),
		'title'   => sanitize_text_field( $input['title'] ?? '' ),
	);
}

add_action( 'admin_menu', function () {
	add_options_page(
		__( 'Acme Reviews', 'acme-reviews' ),
		__( 'Acme Reviews', 'acme-reviews' ),
		'manage_options',
		'acme-reviews',
		function () {
			if ( ! current_user_can( 'manage_options' ) ) {
				return;
			}
			?>
			<div class="wrap">
				<h1><?php echo esc_html( get_admin_page_title() ); ?></h1>
				<form action="options.php" method="post">
					<?php
					settings_fields( 'acme_reviews' );
					do_settings_sections( 'acme-reviews' );
					submit_button();
					?>
				</form>
			</div>
			<?php
		}
	);
} );
```

## Guardrails

- The form posts to `options.php`; `settings_fields()` prints the nonce and option group. Don't hand-roll a save handler for Settings API pages.
- `options.php` checks the `manage_options` capability by default. If the page uses another capability, also filter `option_page_capability_{$option_group}` to match, or saves fail with "Sorry, you are not allowed to manage options".
- The sanitize callback runs on every `update_option()` call for that option (including from code and REST), sometimes twice on the first save. Keep it pure and idempotent; don't send emails or call APIs from it.
- Unchecked checkboxes aren't submitted; sanitize them to `false` explicitly.
- Use `add_settings_error()` in the sanitize callback to report validation problems; WordPress shows them on options pages under Settings automatically. Top-level pages need `settings_errors()` in the page.
- Escape values on output (`esc_attr`, `esc_html`, `esc_textarea`, `checked()`, `selected()`).
- Pass `autoload` deliberately when creating options outside the Settings API (`add_option( $name, $value, '', false )` for rarely read data).
- WP 7.1 adds IDs to section titles generated by the Settings API; don't target section headings by position in CSS/JS.
